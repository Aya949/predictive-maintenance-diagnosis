Quick guidance
What does confidence mean?

It represents the model's estimated confidence in the predicted condition.

What is a contributing factor?

Contributing factors are sensor-derived features identified by the explainability layer as influential for the prediction.

When is an alert sent?

High-confidence non-normal diagnoses can trigger an automated maintenance report email.
